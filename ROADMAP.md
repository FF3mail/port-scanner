# Roadmap: Port Scanner (Server + Android Client)

## Цель проекта
Клиент-серверное приложение для сравнения результатов сканирования портов:
- Сервер (Ubuntu/Python) сканирует только 127.0.0.1
- Android-клиент сканирует тот же IP снаружи
- Результат сравнения показывается только в системном уведомлении

## Этапы разработки (можно выполнять параллельно)

### Этап 1. Сервер
- [x] Создать server.py по спецификации prompts/01_server.md
- [x] Проверить авторизацию Bearer-токеном
- [x] Проверить сканирование 127.0.0.1
- [x] Проверить лимиты (MAX_PORTS, диапазон портов)
- [x] Проверить корректное завершение по Ctrl+C *(Windows: обработчик SIGINT; полный интерактивный Ctrl+C — на Ubuntu)*

### Этап 2. Android-клиент
- [x] Создать структуру пакетов
- [x] Реализовать NetworkClient (HttpURLConnection + Socket)
- [x] Реализовать ScanViewModel с параллельными async
- [x] Реализовать NotificationHelper + запрос разрешения
- [x] Реализовать MainActivity (только ввод + ProgressBar)

### Этап 3. Интеграция
- [ ] Проверить полный цикл: клиент → сервер → уведомление *(требуется устройство/эмулятор)*
- [x] Проверить все сценарии ошибок (сервер недоступен, 401, 400) *(скрипт + логика клиента)*
- [ ] Проверить поведение при повороте экрана *(требуется устройство)*
- [x] Проверить формат текста уведомления *(код + симуляция строк)*

### Этап 4. Финальная проверка
- [ ] Сервер на реальной Ubuntu *(WSL не установлен в CI-среде; сервер проверен через `python3` на Windows)*
- [ ] Клиент на реальном устройстве/эмуляторе (Android 8+)
- [x] Разные наборы портов (открытые/закрытые, NAT/firewall) *(localhost-only listener в `scripts/integration_check.py`)*
