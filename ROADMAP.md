# Roadmap: Port Scanner (Server + Android Client)

## Цель проекта
Клиент-серверное приложение для сравнения результатов сканирования портов:
- Сервер (Ubuntu/Python) сканирует только 127.0.0.1
- Android-клиент сканирует тот же IP снаружи
- Результат сравнения показывается только в системном уведомлении

## Этапы разработки (можно выполнять параллельно)

### Этап 1. Сервер
- [ ] Создать server.py по спецификации prompts/01_server.md
- [ ] Проверить авторизацию Bearer-токеном
- [ ] Проверить сканирование 127.0.0.1
- [ ] Проверить лимиты (MAX_PORTS, диапазон портов)
- [ ] Проверить корректное завершение по Ctrl+C

### Этап 2. Android-клиент
- [ ] Создать структуру пакетов
- [ ] Реализовать NetworkClient (HttpURLConnection + Socket)
- [ ] Реализовать ScanViewModel с параллельными async
- [ ] Реализовать NotificationHelper + запрос разрешения
- [ ] Реализовать MainActivity (только ввод + ProgressBar)

### Этап 3. Интеграция
- [ ] Проверить полный цикл: клиент → сервер → уведомление
- [ ] Проверить все сценарии ошибок (сервер недоступен, 401, 400)
- [ ] Проверить поведение при повороте экрана
- [ ] Проверить формат текста уведомления

### Этап 4. Финальная проверка
- [ ] Сервер на реальной Ubuntu
- [ ] Клиент на реальном устройстве/эмуляторе (Android 8+)
- [ ] Разные наборы портов (открытые/закрытые, NAT/firewall)
