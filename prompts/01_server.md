# 01. Server (Python 3, Ubuntu)

## Файл
server.py

## Жёсткие требования
- Только стандартная библиотека: http.server, socket, json, signal, sys, hashlib, time, os
- Однопоточный HTTPServer (запрещено использовать ThreadingMixIn)
- Порт: 8080
- Запуск: python3 server.py
- Корректное завершение по Ctrl+C (обработчик SIGINT)

### Однопоточность (намеренно)
Сервер обрабатывает запросы последовательно. Пока идёт `/scan`, другие клиенты ждут.
Худшая задержка ≈ `MAX_PORTS * SCAN_TIMEOUT` (например 30 с), если много портов закрыты/фильтруются.
Переход на `ThreadingMixIn` запрещён этой спецификацией.

## Константы (обязательно)
SECRET_TOKEN = os.environ.get("SECRET_TOKEN", "my_secret_123")  # демо-дефолт; в проде — через env
TOKEN_VALIDITY_SECONDS = 6 * 3600  # 21600 с — длина окна Bearer-токена
SCAN_TIMEOUT = 1.0          # секунды на один порт
MAX_PORTS = 30              # жёсткий лимит количества портов

Демо-значение `"my_secret_123"` сохраняется для обратной совместимости, когда env не задан.
В продакшене задавайте `SECRET_TOKEN` через окружение; реальные секреты в репозиторий не коммитить.

## Авторизация (временной Bearer-токен)

Заголовок: `Authorization: Bearer <token>`, где `<token>` — **не** сам `SECRET_TOKEN`, а производное значение для текущего временного окна.

### Алгоритм (детерминированный, совпадает с Android-клиентом)

1. `window_id = floor(unix_timestamp_seconds / TOKEN_VALIDITY_SECONDS)`
2. `token = SHA-256( SECRET_TOKEN + ":" + str(window_id) )` в виде **lowercase hex** (64 символа)

Пример (псевдокод): при `window_id = 42` хешируется строка `"my_secret_123:42"`.

### Проверка на сервере

- Принимаются токены **текущего** окна и **предыдущего** (чтобы запросы на границе смены 6-часового окна не отклонялись).
- Любое несовпадение → HTTP 401 + тело `{"error": "Unauthorized"}`

## Эндпоинт
POST /scan

### Входной JSON (строго этот формат)
{"ports": [22, 80, 443]}

### Правила обработки входа
- Игнорировать любой ключ "host" (даже если он передан)
- Всегда сканировать ТОЛЬКО 127.0.0.1
- ports должен быть списком целых чисел
- Каждый порт должен быть в диапазоне 1..65535
- Максимум MAX_PORTS портов
- Пустой список / отсутствует ключ "ports" / невалидный JSON → HTTP 400 + {"error": "..."}

### Логика сканирования одного порта
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.settimeout(SCAN_TIMEOUT)
result = sock.connect_ex(("127.0.0.1", port))
sock.close()
status = "OPEN" if result == 0 else "CLOSED"

### Успешный ответ (HTTP 200)
{
  "results": {
    "22": "OPEN",
    "80": "CLOSED",
    "443": "OPEN"
  }
}

Требования к ответу:
- Content-Type: application/json; charset=utf-8
- Порядок ключей в results должен совпадать с порядком портов во входном списке
- Статусы только "OPEN" или "CLOSED"

### Ошибки
- 400 Bad Request → {"error": "описание"}
- 401 Unauthorized → {"error": "Unauthorized"}
- 405 Method Not Allowed (разрешён только POST)

## Дополнительно
- Сервер должен корректно завершаться по Ctrl+C
- Не использовать потоки и асинхронность
- Весь код должен быть в одном файле server.py с комментариями

## Формат выдачи
Выдай полный готовый файл server.py без сокращений.
