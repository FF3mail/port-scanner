# 00. Overview + Общий контракт API

## Цель
Создать полностью рабочую систему:
- Сервер (Python 3, Ubuntu) сканирует ТОЛЬКО свои локальные порты 127.0.0.1.
- Клиент (Android, Kotlin) отправляет список портов на сервер, параллельно сам сканирует тот же IP снаружи и показывает сравнение ТОЛЬКО в системном уведомлении (на экране результатов нет).

Разработка сервера и клиента может вестись параллельно.
Общий контракт API зафиксирован ниже и обязателен для обеих сторон.

--------------------------------------------------
## ОБЩИЙ КОНТРАКТ API (обязателен)

Сервер: POST http://<IP>:8080/scan

Заголовок:
Authorization: Bearer my_secret_123

Тело запроса (строго):
{"ports": [22, 80, 443]}

Успешный ответ (HTTP 200):
{
  "results": {
    "22": "OPEN",
    "80": "CLOSED",
    "443": "OPEN"
  }
}

Ошибки:
- 401 → {"error": "Unauthorized"}
- 400 → {"error": "описание ошибки"}
- Content-Type всегда: application/json; charset=utf-8

Статусы портов строго только два значения: "OPEN" или "CLOSED".

Порядок ключей в объекте results должен совпадать с порядком портов во входном списке.
